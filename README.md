# C2 Sinkhole & Tarpit Simulation

This repository contains a static browser-based simulation for demonstrating how a malicious backdoor lifecycle can be interrupted through defensive controls such as:

- malicious script denial
- DNS sinkholing
- resource flood mitigation
- TCP zero-window tarpitting
- live telemetry and socket-state visualization

## Run locally

Open `index.html` directly in a browser.

## Files

- `index.html` — the interactive simulator dashboard

## Notes

This project is intentionally framed as an educational visualization of defensive security controls and network containment. It is not intended to enable unauthorized intrusion or malicious operation.
